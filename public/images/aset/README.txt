FOTO ASET
=========
Letakkan foto aset di folder ini dengan nama sesuai "slug" aset (lihat lib/data.js), format .jpg.

Foto utama           : <slug>.jpg           contoh: aula-d12.jpg
Foto galeri (opsional): <slug>-1.jpg ... <slug>-3.jpg   (halaman detail aset)

Rasio yang disarankan 16:10 (mis. 1600x1000 px). Jika file tidak ada, aplikasi otomatis
menampilkan placeholder bergradasi sehingga tampilan tetap rapi.
